## 5.2.8.1 — WHAT MAKES A SKILL BUNDLED

**Framing.** Bundled skills are prompt-based: they give Claude detailed instructions and let it orchestrate the work with its tools, whereas most built-in commands execute fixed logic directly [Claude Code docs, Skills, 2026]. In the commands reference they are marked as skills.

| Skill | Job |
|---|---|
| `/code-review [level] [--fix] [--comment] [target]` | Review the diff, a PR, branch or path for correctness bugs; alias `/review` |
| `/simplify [target]` | Four parallel review agents for cleanup (reuse, simplification, efficiency, abstraction level); applies fixes; no bug hunt |
| `/batch <instruction>` | Decompose into 5 to 30 independent units, plan, then one background subagent per unit in an isolated worktree |
| `/debug [description]` | Enable debug logging and read the session debug log |
| `/loop [interval] [prompt]` | Re-run a prompt while the session stays open; alias `/proactive` |
| `/verify` | Build and run your app to confirm a change, not only tests |
| `/run`, `/run-skill-generator` | Launch and drive the app; write a per-project run skill |
| `/doctor` | Setup checkup, proposes fixes applied after confirmation |
| `/update-config [request]` | Edit settings.json from a description |
| `/fewer-permission-prompts` | Scan transcripts and add a read-only allowlist to project settings |
| `/claude-api`, `/claude-in-chrome`, `/dataviz`, `/design`, `/design-sync`, `/slides` | API reference, browser tasks, chart guidance, design canvases, design-system sync, slide decks |

[Claude Code docs, Commands, 2026; table abridged. The list changes by version, so check `/` in your own build.]

The failure mode: **Reinvented bundle.** You write your own review skill that duplicates `/code-review` and maintain it forever.

The fix: Run the bundled one first; write your own only for what it does not cover.

Cross-references: subagents are Module 5.3; worktrees are Module 6.2; large-scale change is Module 6.5.

**If you remember one thing:** check the bundle before building.

## 5.2.8.2 — REVIEW VERSUS SIMPLIFY

**Framing.** These two are easy to confuse. `/code-review` looks for correctness bugs and, depending on model and effort, cleanup opportunities; `--fix` applies findings, `--comment` posts to a GitHub PR or GitLab merge request, and `ultra` runs a deeper cloud review. `/simplify` runs four agents for cleanup and explicitly does not look for correctness bugs [Claude Code docs, Commands, 2026].

| Question | Use |
|---|---|
| Is this change wrong? | `/code-review` |
| Is this change messy or duplicated? | `/simplify` |
| Is it safe to ship? | `/verify` after both |

The failure mode: **Cleanup-as-correctness.** You run `/simplify`, see a clean result and assume the logic was reviewed.

The fix: Run `/code-review` for bugs; treat `/simplify` as cleanup only.

Cross-references: verification is Module 2.3.

**If you remember one thing:** cleanup is not correctness.

## 5.2.8.3 — RUN, VERIFY AND SCALE

**Framing.** `/run` and `/verify` work without setup but inference becomes unreliable for projects needing more than a standard launch; `/run-skill-generator` records the recipe as a per-project skill at `.claude/skills/run-<name>/`, to be run once per project and again if the build or launch changes [Claude Code docs, Skills, 2026]. `/batch` needs a git repository or a `WorktreeCreate` hook; outside git it needs v2.1.281 or later [Claude Code docs, Commands, 2026].

| Task | Skill chain |
|---|---|
| Prove a change works in the running app | `/run-skill-generator` once, then `/verify` |
| Migrate 200 files | `/batch migrate src/ from JavaScript to TypeScript` |
| Watch a deploy | `/loop 5m check if the deploy finished` |

The failure mode: **Batch-without-plan.** You launch a batch of dozens of parallel units without reading the proposed plan, and approve decomposition that overlaps.

The fix: Read the plan before approving; `/batch` presents one first.

Cross-references: dynamic workflows are Module 6.5; loops are Module 6.7.

**If you remember one thing:** approve the plan, not just the command.
