## 14.1.11.1 — DEEP RESEARCH AS A WORKFLOW

**Framing.** `/deep-research <question>` is a bundled dynamic workflow that fans out web searches, fetches and cross-checks sources and synthesises a cited report; it runs in the background across many subagents [Claude Code docs, Commands, 2026].

| Property | Value |
|---|---|
| Type | Workflow, not a plain skill |
| Trigger | You invoke it (since v2.1.218) |
| Output | Cited report |
| Runs | Background, many subagents |

The failure mode: **Citation-trust.** You paste the report's claims into a decision memo without opening the sources.

The fix: Open at least three citations and flag any that do not support the claim.

Cross-references: workflows are Module 6.5.

**If you remember one thing:** citations are leads.

## 14.1.11.2 — CLAUDE API REFERENCE

**Framing.** `/claude-api [migrate|upgrade|managed-agents-onboard|prompt-audit|cost-optimize|build-eval|hillclimb|preserved-thinking-migration]` is a bundled skill loading Claude API and Managed Agents reference material for your project's language, and it also activates automatically when relevant [Claude Code docs, Commands, 2026].

| Mode | Use |
|---|---|
| `migrate`, `upgrade` | Move code to newer models or API |
| `prompt-audit` | Review prompts |
| `cost-optimize` | Reduce spend |
| `build-eval`, `hillclimb` | Evaluation work |
| `managed-agents-onboard` | Managed Agents |

The failure mode: **Mode-guessing.** You invoke `/claude-api` with a mode name that does not exist and get generic output.

The fix: Copy mode names from the argument list above.

Cross-references: SDK work is Module 8.4; evals are Module 17.3 in spirit and Volume C.

**If you remember one thing:** use listed modes only.

## 14.1.11.3 — CHOOSING THE TOOL

**Framing.** A single question rarely needs a fan-out workflow; `/deep-research` costs many subagent requests and runs in the background, so use a plain search for lookups.

| Question type | Tool |
|---|---|
| One fact | Web search |
| Broad, multi-source | `/deep-research` |
| API usage in your code | `/claude-api` |

The failure mode: **Fan-out-for-a-fact.** You launch deep research for a one-line fact and burn usage on a workflow.

The fix: Reserve it for questions needing several sources and a synthesis.

Cross-references: cost control is Module 1.4.

**If you remember one thing:** match the tool to the breadth.
