## 14.2.7.1 — ENABLE AND MODES

**Framing.** Vim-style editing is enabled via `/config` then Editor mode; Claude Code keeps your mode and cursor position when you toggle the transcript viewer or open a panel. `Esc` or `Ctrl+[` enters NORMAL mode, and `i`, `I`, `a`, `A`, `o`, `O` enter INSERT; `v` and `V` start visual selection [Claude Code docs, Interactive mode, 2026]. The older `/vim` command was removed in v2.1.92 [Claude Code docs, Commands, 2026].

| Key (NORMAL) | Action |
|---|---|
| `i` / `I` | Insert before cursor / at line start |
| `a` / `A` | Insert after cursor / at line end |
| `o` / `O` | Open line below / above |
| `v` / `V` | Visual char / line |

The failure mode: **Escape-expectation.** You press Escape expecting to cancel and instead enter NORMAL mode, then type text that acts as commands.

The fix: Check the mode indicator, and in NORMAL mode press Escape again where the context cancels.

Cross-references: terminal setup is Module 9.1.

**If you remember one thing:** Escape changes mode first.

---

## 14.2.7.2 — REMAPPING

**Framing.** Vim keys are not remappable through keybindings.json. To map a two-key INSERT sequence such as `jj` to Escape, use the `vimInsertModeRemaps` setting [Claude Code docs, Keybindings, 2026] [Claude Code docs, Interactive mode, 2026].

| Want | Use |
|---|---|
| `jj` to leave INSERT | `vimInsertModeRemaps` setting |
| Rebind Ctrl keys | keybindings.json |

The failure mode: **Wrong-remap-file.** You put a vim remap in keybindings.json and it never fires.

The fix: Use the `vimInsertModeRemaps` setting.

Cross-references: settings are Module 4.1.

**If you remember one thing:** vim keys live in settings.

---

## 14.2.7.3 — INTERACTIONS

**Framing.** In vim NORMAL mode `?` shows the help menu and `/` opens history search. In the `Other` row of a question, Escape does not cancel at once: it switches mode or drops a half-typed command, and a second Escape in NORMAL mode cancels; binding a Ctrl key to `select:cancel` in `Select` cancels with one press [Claude Code docs, Keybindings, 2026].

```json
{"bindings":[{"context":"Select","bindings":{"ctrl+q":"select:cancel"}}]}
```

The failure mode: **Stuck-question.** You cannot dismiss a question in vim mode because Escape only changes mode.

The fix: Press Escape twice, or bind a Ctrl key to `select:cancel`.

Cross-references: agent questions are Module 2.2.

**If you remember one thing:** two Escapes in vim mode.
