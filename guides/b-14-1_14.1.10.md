## 14.1.10.1 — FIND AND MANAGE ARTIFACTS

**Framing.** `/artifacts` lists artifacts you own or that are shared with you, then attaches one to the session, opens it or copies its link; it needs v2.1.208 or later and attaching with Enter needs v2.1.216, and it is available where artifacts are [Claude Code docs, Commands, 2026]. `/artifact-capabilities` and `/artifact-diagramming` load reference skills; the latter needs v2.1.221 or later [Claude Code docs, Commands, 2026].

| Command | Needs |
|---|---|
| `/artifacts` | v2.1.208+; attach needs v2.1.216 |
| `/artifact-capabilities` | Artifact availability |
| `/artifact-diagramming` | v2.1.221+ |

The failure mode: **Version-blind.** You tell a teammate to attach an artifact with Enter on a version older than the one that supports it.

The fix: Quote the minimum version next to every command in a team guide.

Cross-references: artifacts are Module 9.2.

**If you remember one thing:** write the version with the command.

## 14.1.10.2 — DESIGN AND SLIDES

**Framing.** `/design [brief]` drafts UI mockups, flows, landing pages or posters as artboards on a canvas published as a Claude Design artifact. `/design-login` authorises design-system access, and `/design-sync [hint]` converts your React design system and uploads it so designs use your components; it needs the Anthropic API. `/slides [brief]` makes a Claude Slides artifact and needs v2.1.265 or later [Claude Code docs, Commands, 2026].

| Command | Output | Gate |
|---|---|---|
| `/design a settings screen` | Artboards | Artifact availability |
| `/design-login` | Authorisation | claude.ai account |
| `/design-sync Acme DS` | Uploaded design system | Anthropic API; slow first run |
| `/slides a quarterly review` | Slide artifact | v2.1.265+ |

The failure mode: **Sync-on-deadline.** You start `/design-sync` an hour before a review and it is still verifying components.

The fix: Run the first sync well ahead and treat later syncs as incremental.

Cross-references: prototyping is Module 7.1.

**If you remember one thing:** plan the first sync.

---

## 14.1.10.3 — CHARTS

**Framing.** `/dataviz [request]` is a bundled skill giving design guidance for charts: it picks the chart form, assigns colour by role, validates the palette for colour-blind safety and contrast with a bundled script, and uses a brand-neutral placeholder palette you replace [Claude Code docs, Commands, 2026].

```text
/dataviz a retention curve by cohort, colour-blind safe
```

| Step | Done by |
|---|---|
| Choose form | Skill |
| Palette validation | Bundled script |
| Brand palette | You replace the placeholder |

The failure mode: **Placeholder-palette.** You ship a chart with the placeholder palette and it carries no brand identity.

The fix: Replace the palette values before publishing.

Cross-references: product communication is Module 7.1.

**If you remember one thing:** swap the palette.
