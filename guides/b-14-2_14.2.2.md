## 14.2.2.1 — SINGLE ESCAPE

**Framing.** Escape interrupts the current response or tool call mid-turn; Claude keeps the work done so far, and queued messages are sent next. In a dialog it closes the dialog, with a footer item selected it deselects it, and on a permission prompt it declines the action like No [Claude Code docs, Interactive mode, 2026].

| State | Escape does |
|---|---|
| Claude responding | Interrupts; work kept |
| Dialog open | Closes dialog |
| Footer row selected | Deselects it |
| Permission prompt | Declines the action |

The failure mode: **Wrong-focus-escape.** You press Escape to stop a run while a footer row is selected and only deselect it, so the run continues.

The fix: Press Escape again, or `Ctrl+C`, after checking focus.

Cross-references: the loop and interrupting are Module 1.2.1.

**If you remember one thing:** check focus first.

## 14.2.2.2 — DOUBLE ESCAPE

**Framing.** With text in the prompt, `Esc Esc` clears the draft and saves it to history so Up recalls it. With an empty input it opens the rewind menu to restore or summarise code and conversation from an earlier point [Claude Code docs, Interactive mode, 2026].

| Prompt | `Esc Esc` | Recover |
|---|---|---|
| Has text | Clears and saves draft | Press Up |
| Empty | Opens rewind menu | Choose a point |

The failure mode: **Draft-wipe.** You double-press Escape on a long draft meaning to open rewind and lose your place.

The fix: Submit or stash with Ctrl+S first, or press Up to recall.

Cross-references: checkpoints are Module 2.5.

**If you remember one thing:** double Escape reads the prompt state.

---

## 14.2.2.3 — RELATED KEYS

**Framing.** `Ctrl+C` interrupts or clears input, and a second press with nothing running exits; a cleared draft returns with Up on v2.1.288 or later, and the ten most recent cleared drafts are kept for the session from v2.1.292 [Claude Code docs, Interactive mode, 2026]. `Ctrl+S` stashes the prompt.

| Key | Use |
|---|---|
| `Ctrl+C` | Interrupt or clear |
| `Ctrl+S` | Stash and restore a draft |
| `Up` | Recall cleared draft |

The failure mode: **Exit-by-reflex.** You press Ctrl+C twice by reflex and exit the session.

The fix: Press once, read the hint, then decide.

Cross-references: sessions are Module 2.4.

**If you remember one thing:** one Ctrl+C at a time.
