## 14.1.7.1 — SKILLS

**Framing.** `/skills` lists available skills; press `t` to sort by token count and `Space` or `Enter` to cycle a skill's visibility. `/skill-doctor` shows what each skill costs in context and how often it is used, and needs v2.1.252 or later plus feature-flag fetching. `/reload-skills` re-scans skill and command directories so skills added on disk become available without a restart and reports how many were added or removed [Claude Code docs, Commands, 2026].

| Command | Answers |
|---|---|
| `/skills` | What is available? Sort by tokens |
| `/skill-doctor` | Which skills cost most or go unused? |
| `/reload-skills` | Did my new SKILL.md load? |

The failure mode: **Phantom-skill.** You add a skill folder mid-session and Claude never uses it because nothing reloaded.

The fix: Run `/reload-skills`, read the added count, then check `/skills`.

Cross-references: skills are Module 5.2.

**If you remember one thing:** reload, then confirm the count.

## 14.1.7.2 — PLUGINS AND HOOKS

**Framing.** `/plugin [subcommand]` opens the plugin menu or acts directly with `list`, `install`, `enable` or `disable`; `/reload-plugins [--force]` applies pending changes and warns and skips when the reload would change loaded MCP tools and invalidate the prompt cache unless you pass `--force`. `/hooks` views hook configurations [Claude Code docs, Commands, 2026].

| Command | Effect |
|---|---|
| `/plugin install <name>` | Install; the summary says whether it activated |
| `/reload-plugins` | Apply pending changes |
| `/reload-plugins --force` | Reload even if it invalidates the cache |
| `/hooks` | Read-only view of configured hooks |

The failure mode: **Forced-reload-habit.** You always pass `--force` and pay for an uncached conversation re-read each time.

The fix: Reload without `--force` first and force only when the warning is acceptable.

Cross-references: plugins are Module 5.6; hooks are Module 5.4.

**If you remember one thing:** the warning is a cost notice.

## 14.1.7.3 — AGENTS AND INTEGRATIONS

**Framing.** `/agents` prints a reminder to ask Claude to create or manage subagents or to edit `.claude/agents/` or `~/.claude/agents/`; on v2.1.197 and earlier it opened an interface. `/chrome` configures Claude in Chrome, `/ide` manages IDE integrations and shows status and `/install-slack-app` opens a browser for OAuth [Claude Code docs, Commands, 2026].

| Command | Today |
|---|---|
| `/agents` | Reminder page |
| `/chrome` | Chrome settings |
| `/ide` | IDE status |
| `/install-slack-app` | OAuth in browser |

The failure mode: **Stale-tutorial.** A blog tells you to use the `/agents` interface and you search for a menu that no longer exists.

The fix: Check the Commands page and your `claude --version` before following an older tutorial.

Cross-references: subagents are Module 5.3; IDE and browser are Module 9.1.

**If you remember one thing:** docs beat tutorials.
