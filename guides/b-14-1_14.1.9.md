## 14.1.9.1 — IDENTITY AND QUOTA

**Framing.** `/login` signs in to your Anthropic account and `/logout` signs out. `/usage` shows session cost, plan usage limits and activity stats; on Pro, Max, Team or Enterprise it includes a breakdown of what counts against plan limits; `/cost` and `/stats` are aliases, and `/stats` opens on the Stats tab [Claude Code docs, Commands, 2026].

| Command | Does |
|---|---|
| `/login`, `/logout` | Switch identity |
| `/usage` | Cost, plan limits, stats |
| `/cost` | Same as `/usage` |
| `/stats` | `/usage` on the Stats tab |

The failure mode: **Alias-hunting.** You search for a separate cost command and miss that `/cost` and `/stats` are the same panel as `/usage`.

The fix: Use `/usage` and its tabs.

Cross-references: usage and cost is Module 1.4.

**If you remember one thing:** one read-out, three names.

## 14.1.9.2 — WHEN YOU HIT A LIMIT

**Framing.** `/rate-limit-options` shows ways to keep working when a claude.ai limit blocks a request: wait and continue automatically on reset, add usage credits, or upgrade. `/usage-credits` configures credits or requests them from an admin on Team and Enterprise; `/upgrade` opens the upgrade page and does not show on Enterprise plans [Claude Code docs, Commands, 2026].

| Option | Command |
|---|---|
| Wait and auto-continue | `/rate-limit-options` |
| Add credits | `/usage-credits` |
| Higher tier | `/upgrade` |

Availability varies by platform, plan and version; if a command is missing, run `/help` and check `claude --version` before assuming it does not exist.

The failure mode: **Mid-task-stall.** You start a long run near a limit and it halts halfway with partial changes.

The fix: Read `/usage` first and size the task to the remaining window, or commit a checkpoint before starting.

Cross-references: limits and windows are Module 1.4.

**If you remember one thing:** size the task to the window.

---

## 14.1.9.3 — TEAM HANDLING

**Framing.** Team and Enterprise members without billing access send a request to their admin through `/usage-credits` [Claude Code docs, Commands, 2026]. `/config` cannot turn on `autoContinueAtUsageLimit` by key=value because it needs confirmation in the panel [Claude Code docs, Commands, 2026].

| Role | Path |
|---|---|
| Individual | Credits via billing settings |
| Member without billing | Request sent to admin |
| Admin | Approves or buys |

The failure mode: **Silent-request.** You request credits and keep working without telling the admin, so the request sits unseen.

The fix: Message the admin as well, and define who approves.

Cross-references: enterprise rollout is Module 10.1.

**If you remember one thing:** requests need a human owner.
