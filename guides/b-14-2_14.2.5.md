## THE THESIS OF THIS TOPIC

**Three input prefixes put things into context directly: @ for files, ! for shell commands whose output Claude sees, and image paste.**

## 14.2.5.1 — @ FILE MENTIONS

**Framing.** `@` triggers file path autocomplete. In sessions with cross-session messaging, typing at least one letter after `@` also suggests other live sessions on the machine; that requires v2.1.232 or later [Claude Code docs, Interactive mode, 2026].

```text
Explain the retry logic in @src/net/client.ts
```

| Typed | Effect |
|---|---|
| `@src/` | Path autocomplete |
| `@` plus a letter, with messaging on | Also suggests live sessions |

The failure mode: **Whole-repo-mention.** You mention a very large file or a broad directory and spend context on content you did not need.

The fix: Mention the specific file or range and check `/context`.

Cross-references: context cost is Module 3.1.

**If you remember one thing:** mention precisely.

## 14.2.5.2 — ! SHELL MODE

**Framing.** A leading `!` runs a command directly, adds the command and output to the conversation and shows live progress; it supports Ctrl+B backgrounding, Tab completion from previous `!` commands and exits with Escape, Backspace or Ctrl+U on an empty prompt. Claude responds to the output automatically at the cost of a normal prompt; set `respondToBashCommands` to false to add the output without a response [Claude Code docs, Interactive mode, 2026].

```text
! npm test
```

| Property | Value |
|---|---|
| Needs Claude approval | No |
| Sandboxed | No (outside strict sandbox mode sessions) |
| Costs a response | Yes, unless `respondToBashCommands` is false |

The failure mode: **Unsandboxed-shell.** You type a risky command in shell mode assuming the sandbox protects it, and it runs with your full access.

The fix: Treat shell mode as your own terminal and check commands before pressing Enter.

Cross-references: sandboxing is Module 4.4.

**If you remember one thing:** shell mode is you, not Claude.

---

## 14.2.5.3 — IMAGES

**Framing.** `Ctrl+V` (`Cmd+V` in iTerm2, `Alt+V` on Windows and WSL) pastes an image and inserts an `[Image #N]` chip you can reference by number in the prompt [Claude Code docs, Interactive mode, 2026].

| Platform | Paste key |
|---|---|
| Most terminals | Ctrl+V |
| iTerm2 | Cmd+V |
| Windows, WSL | Alt+V (WSL binds both) |

The failure mode: **Sensitive-screenshot.** You paste a screenshot that contains secrets or customer data into a session that is stored as a transcript.

The fix: Crop or redact before pasting.

Cross-references: transcript privacy is Module 11.1.

**If you remember one thing:** screenshots are stored too.
